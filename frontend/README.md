# MONITOKYOGAS Frontend

Vue 3 + TypeScript dashboard for CSV files generated by the MONITOKYOGAS backend.

## Configuration

Copy the env template:

```bash
cp .env.example .env
```

Set `VITE_GITHUB_OWNER`, `VITE_GITHUB_REPO`, and `VITE_DATA_BRANCH` so the dashboard can load CSV files from GitHub raw content.

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```
